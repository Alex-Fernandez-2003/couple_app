# Couple App - Coding Standards

## Flutter

- Use Riverpod for state management
- Prefer StatelessWidget when possible
- Keep widgets small and modular
- Avoid unnecessary rebuilds

## Dart

- Prefer final variables
- Avoid dynamic unless necessary
- Keep models immutable when possible

## UI

- Maintain soft pink aesthetic
- Keep smooth animations
- Prefer warm and clean UX

## Architecture

- Local-first when possible
- Supabase only for shared couple features
- Notes, shopping, audio and files stay local

## Code Safety

- Avoid force unwraps
- Handle async errors
- No setState after dispose
- Dispose controllers properly
